# Selenium Automation – Login Page Testing

This repository contains Selenium WebDriver automation code for testing a Login Page.  
The project demonstrates automated validation of login functionality using Java and Selenium, following best practices in test automation.

## Features
- Automated testing of Login Page
- Valid and Invalid login test scenarios
- Basic wait handling
- Clean and readable test structure

## Tech Stack
- Programming Language: Java  
- Automation Tool: Selenium WebDriver  
- IDE: Eclipse
- Browser: Chrome
